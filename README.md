# Endless Money — Financial Tracker

**Endless Money** — мобильное Android-приложение для учёта личных финансов.  
Проект позволяет отслеживать доходы и расходы, просматривать баланс, работать с категориями транзакций и отображать данные в удобном интерфейсе.

## Описание проекта

Приложение разработано как учебный Android-проект с использованием современной архитектуры и актуального стека технологий.

Основная идея проекта — создать финансовый трекер, в котором пользователь может:

- просматривать общий баланс;
- добавлять доходы и расходы;
- видеть список последних транзакций;
- распределять операции по категориям;
- работать с несколькими счетами;
- менять настройки приложения;
- использовать выбранную валюту;
- получать актуальные курсы валют через интернет.

Проект построен с разделением на слои `Data`, `Domain` и `UI`, что делает код более понятным, расширяемым и удобным для поддержки.

## Основной функционал

Приложение реализует следующие возможности:

- отображение текущего баланса;
- добавление новой транзакции;
- просмотр последних операций;
- разделение транзакций на доходы и расходы;
- работа с категориями;
- работа со счетами;
- сохранение настроек пользователя;
- скрытие баланса в интерфейсе;
- выбор валюты;
- получение курсов валют через API;
- автоматическое обновление интерфейса при изменении данных.

## Используемые технологии

В проекте используются:

- **Kotlin** — основной язык разработки;
- **Jetpack Compose** — создание пользовательского интерфейса;
- **Material 3** — современный дизайн интерфейса;
- **Room** — локальная база данных;
- **Flow** — реактивное обновление данных;
- **Koin** — внедрение зависимостей;
- **Ktor Client** — работа с сетевыми запросами;
- **kotlinx.serialization** — обработка JSON;
- **DataStore** — хранение пользовательских настроек;
- **Clean Architecture** — разделение проекта на слои;
- **MVVM** — организация логики экранов через ViewModel.

Он включает:

Слой domain содержит бизнес-логику приложения.

В нём находятся:

Примеры use case:

Слой presentation отвечает за интерфейс и взаимодействие с пользователем.

Для хранения данных используется Room.

Основные сущности:

TransactionEntity

id;

id;

Работа с данными

Для автоматического обновления интерфейса используется Flow.

Это позволяет приложению сразу обновлять данные на экране после изменения базы данных.
Например, после добавления новой транзакции список операций и баланс могут обновляться автоматически.

Работа с валютами

Приложение поддерживает работу с валютами.

Для получения курсов валют используется сетевой клиент Ktor.
Данные могут загружаться из внешнего API и использоваться для отображения баланса в выбранной валюте.

Также предусмотрено хранение настроек пользователя через DataStore, например:

выбранная валюта;
скрытие баланса;
пользовательские параметры интерфейса.
Интерфейс приложения

Интерфейс реализован с помощью Jetpack Compose и Material 3.

Основной экран приложения содержит:

список последних операций;
переход к списку всех транзакций;

Обработка состояний

Для экранов используется подход LCE:

Loading — загрузка данных
Content — отображение данных
Error — отображение ошибки

Это позволяет корректно показывать пользователю состояние приложения при загрузке данных, ошибках сети или отсутствии данных.
